APEX X PLAYER INFO BOT

FILES
-----
bot.py              Main bot
channels.txt        Required channels for verification
requirements.txt    Python dependencies

INSTALL
-------
pip install -r requirements.txt

CHANNELS.TXT
------------
Add one public channel per line.

Supported:
@ChannelUsername
https://t.me/ChannelUsername
t.me/ChannelUsername

You can add future channels simply by adding another line.

IMPORTANT
---------
For force-join verification, add the bot as administrator
in each channel listed in channels.txt.
